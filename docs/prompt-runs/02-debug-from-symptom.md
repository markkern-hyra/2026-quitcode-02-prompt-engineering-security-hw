## 02a — v1

| | |
|---|---|
| Ходів / вартість / час | 19 / $0.66 / 153 с |
| Відтворення | з 4-ї спроби: `node -e "require('./dist/quote.js')"` → немає `dist`; `npm run build` → немає скрипта; `npx tsx -e …` (імпорт `.js`) → **npm завантажив `tsx@4.23.13` з мережі**, але впало на імпорті; `npx tsx -e …` (імпорт `.ts`) → вивід із розбіжністю |
| Першопричина | «`Math.round(totalCents / parts)` округлює до найближчого цілого…» — `app/src/quote.ts:32` |
| Виправлення | `Math.floor` + цикл, що додає по 1 центу першим `remainder` платежам |
| `npm test` / typecheck | ✅ 41 passed, 0 expected fail / ✅ |
| Acceptance criteria | 8 з 8 ✅ |

Незалежна перевірка (поза агентом): усі комбінації `totalCents` 0..2000 ×
`parts` 1..40 — 80 040 шт. — довжина, сума, `max − min ≤ 1`, незростання,
цілі значення: **0 порушень**.

**Що пропустили критерії.** Моє порівняння старої й нової версії на входах,
які контракт не визначає:

| Вхід | До | Після v1 |
|---|---|---|
| `(100, -1)` | `RangeError: Invalid array length` | `[]` |
| `(100, 2.5)` | `RangeError: Invalid array length` | **`[40, 40, 40]` — сума 120** |
| `(-100, 3)` | `[-33, -33, -33]` | `[-33, -33, -34]` |
| `(100.5, 2)` | `[50, 50]` | `[51, 50]` |

Промпт забороняв змінювати невизначену поведінку, але жоден критерій цього не
перевіряв — і агент не згадав зміну навіть у «Помічено, але не чіпав». Гучна
помилка на дробовому `parts` перетворилась на тихо неправильну суму.
**Рішення:** v1 не мержимо, промпт → v2.

## 02b — v2

Додано: критерій і розділ звіту «невизначені входи: до / після», заборона
пакетів поза `package.json`.

| | |
|---|---|
| Ходів / вартість / час | 31 / $1.07 / 222 с |
| Відтворення | `node --experimental-strip-types src/reproduce.ts` — з 2-ї спроби (перша: `ERR_MODULE_NOT_FOUND` на імпорті, агент виправив шлях у скрипті), без завантажень; тимчасові файли прибрав сам |
| Виправлення | `Math.floor` + `Array.from({ length: parts }, …)` |
| `npm test` / typecheck | ✅ 41 passed, 0 expected fail / ✅ |
| Незалежна перевірка 80 040 комбінацій | ✅ 0 порушень |

Таблиця зі звіту агента:

| Вхід | До | Після | Змінилось? |
|---|---|---|---|
| `parts = 0` | `[]` | `[]` | Ні |
| `parts = -3` | `Error: Invalid array length` | `[]` | **Так** |
| `parts = 2.5` | `Error: Invalid array length` | `[40, 40]` | **Так** |
| `totalCents = -100` | `[-33, -33, -33]` | `[-33, -33, -34]` | **Так** |
| `totalCents = 100.5` | `[34, 34, 34]` | `[34, 34, 33]` | **Так** |

> «Зміни в невизначеній поведінці не є частиною контракту — рішення за людиною.»

v2 теж змінює поведінку на дробовому `parts` (без валідації інакше не
вийде), але тепер це **видно у звіті**, а не виявляється потім. Рішення
людини — контракт лишається відкритим питанням; фактична поведінка фіксується
в документації (прогін `document-module`).

## Спостереження про дозволи

- **`npx:*` у allowlist = дозвіл завантажити й виконати будь-який пакет із
  npm.** У v2 текстова заборона спрацювала, але це трималося на моделі. Після
  цього прогону allowlist наступних прогонів звужено: `npm test`,
  `npm run typecheck`, `node`, `git diff|status|log|checkout` — без `npx` і
  без довільних `npm`.
- **`rm` не було в allowlist**, але в режимі `acceptEdits` обидві команди `rm`
  (прибирання тимчасових файлів) виконались без запиту й без відмови:
  `acceptEdits` дозволяє більше, ніж «редагування». Це враховано в Task C.

## 02c — v3 (після рев'ю CodeRabbit)

Що змінено в промпті: прибрано суперечність «не змінюй невизначену поведінку» vs
«покажи таблицю цих змін» (тепер зміна дозволена лише зі звітом і рішенням
людини); відтворення — тимчасовим тестом Vitest, бо в проєкті заборонено
`Bash(node:*)`; Stop — з `typecheck`. Прогін — від того самого `b300474`, з
налаштуваннями, де `Bash(node:*)` у `deny` (і водночас явно дозволений в
allowlist — перевірка, що `deny` перемагає). Сирий вихід —
[`e1-debug-v3`](./raw/e1-debug-v3.md).

| | |
|---|---|
| Ходів / вартість / час | 27 / $1.15 / 245 с |
| Відтворення | `npm test -- src/_repro.test.ts --reporter=verbose` з `console.log`; **0 спроб `node`**; тимчасовий файл видалено |
| Виправлення | те саме, що у v2 (`Math.floor` + `Array.from`) |
| `npm test` / typecheck (незалежно) | ✅ 43 passed (4 регресійні тести) / ✅; `it.fails` не лишилось |
| Невизначені входи | таблиця з 5 рядків: `parts = 0` — без змін; `parts = -3` і `2.5` (→ `[40, 40]`, сума 80), `totalCents = -100` — **змінились** і позначені; `totalCents = 50.5` — без змін |
| Відмови в дозволах | 2: `git -C …` (поза allowlist) і `Glob **/_repro.test.ts` |

Суперечність зникла: агент змінив поведінку лише як побічний ефект виправлення,
позначив кожну зміну й не додавав валідації. На гілку нічого не бралось —
виправлення ідентичне вже закоміченому.
