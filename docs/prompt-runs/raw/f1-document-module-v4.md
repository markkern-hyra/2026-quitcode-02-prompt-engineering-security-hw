## 7. Помічено, але не чіпав

1. **formatMoney з дробовими центами** — `formatMoney(100.5)` дає `"$1.0.5"` замість очікуваного `"$1.01"`. Причина: `abs % 100` для 100.5 дає 0.5, і `String(0.5).padStart(2, "0")` → `"0.5"`. Код передбачає цілі центи.

2. **splitInstallments з parts=0** — повертає `[]` без помилки. Це може бути несподіваною поведінкою; сума порожнього масиву = 0, а не totalCents.

3. **splitInstallments з дробовим parts** — `Array.from({ length: 2.5 })` створює масив довжини 2. Це приховане усічення без попередження.

4. **Відсутня валідація** всіх вхідних параметрів: від'ємні години/ставки, знижка поза 0–100, parts ≤ 0, дробові центи — все це прийнято мовчки, без помилки.
