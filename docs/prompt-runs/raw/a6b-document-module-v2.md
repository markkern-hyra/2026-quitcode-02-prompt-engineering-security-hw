## 4. Помічено, але не чіпав

1. **`formatMoney` з дробовими центами** — некоректний вивід (`"$1.0.5"`). Код використовує `abs % 100`, що для дробових чисел дає дробовий залишок. Потрібно або валідувати вхід, або округлювати перед обчисленням.

2. **`splitInstallments(-100, 3)` повертає `[-33, -33, -34]`** — залишок `-1` додається до останнього елемента, а не до перших, що суперечить поведінці з додатними числами. Причина: `Math.floor(-100/3) = -34`, `remainder = -100 - (-34*3) = 2`, тому `i < 2` дає `[-33, -33, -34]`. Неконсистентна логіка.

3. **Відсутня валідація входів** — жодна функція не перевіряє типи/діапазони; код мовчки обчислює безглузді результати (від'ємні ціни, порожні масиви, знижки понад 100%).
