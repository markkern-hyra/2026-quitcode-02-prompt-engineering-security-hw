## Підсумок

### 1. Відтворення (до змін)

**Команда:**
```bash
npx tsx -e "import { splitInstallments } from './src/quote.ts'; ..."
```

**Вивід:**
```
Випадок 1: $1.00 на 3 платежі
  splitInstallments(100, 3) = [ 33, 33, 33 ]
  Сума: 99 центів, очікувалось: 100 центів
  Розбіжність: -1 центів

Випадок 2: $1,000.07 на 7 платежів
  splitInstallments(100007, 7) = [ 14287, 14287, 14287, 14287, 14287, 14287, 14287 ]
  Сума: 100009 центів, очікувалось: 100007 центів
  Розбіжність: 2 центів
```

### 2. Першопричина

`Math.round(totalCents / parts)` округлює до найближчого цілого (вгору або вниз), тому сума `parts` однакових частин не дорівнює `totalCents`. — `app/src/quote.ts:32`

### 3. Виправлення: диф `app/src/quote.ts`

```diff
 export function splitInstallments(totalCents: number, parts: number): number[] {
-  const each = Math.round(totalCents / parts);
-  return new Array(parts).fill(each);
+  const base = Math.floor(totalCents / parts);
+  const remainder = totalCents - base * parts;
+  const result: number[] = [];
+  for (let i = 0; i < parts; i++) {
+    result.push(i < remainder ? base + 1 : base);
+  }
+  return result;
 }
```

### 4. Які тести змінено й додано — і чому

**Змінено:**
- 3 тести `it.fails` у `splitInstallments — крайові випадки` перетворено на звичайні `it`, прибрано коментарі `// ВАДА:`.
- У `splitInstallments — інваріант «сума частин дорівнює цілому»` прибрано логіку `if (divisible) ... else it.fails`, тепер усі випадки тестуються однаково через `it`.

**Додано:**
- Новий describe-блок `splitInstallments — регресія для симптомів бухгалтерії` з двома тестами:
  1. `$1.00 на 3 платежі → [34, 33, 33], сума = 100` — перевіряє точний результат і суму.
  2. `$1,000.07 на 7 платежів → сума = 100007` — перевіряє суму, довжину, що частини не зростають і різниця ≤ 1.

### 5. Помічено, але не чіпав

- Немає валідації для `parts ≤ 0`, від'ємних чи дробових значень `totalCents` або `parts`.
- `estimateTotalCents` може мати похибки округлення при великих знижках (не є предметом цього бага).
- Поле `divisible` у `testCases` більше не використовується, але залишене — видалення не входить у scope.
